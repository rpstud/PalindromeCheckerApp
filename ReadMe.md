# Palindrome Checker App

A comprehensive Java application that demonstrates various ways to check for palindromes using different data structures, design patterns, and logic levels. This project is structured across 13 distinct use cases to showcase progressive development.

## 🚀 Overview

The **Palindrome Checker App** is designed to validate whether a given string is a palindrome (reads the same forwards and backwards). The project evolves from simple string manipulation to advanced implementations using Interfaces, the Strategy Pattern, Stacks, and Deques.

## 📂 Repository Structure

This repository uses a branch-based progression system. Each branch represents a specific stage of the project:

- **master/main**: Contains only the documentation (`README.md`).
- **uc1 - uc13**: Feature branches containing specific `src/Main.java` implementations.

## 🗺️ Branch Roadmap

| Branch | Description | Key Tech / Concepts |
| :--- | :--- | :--- |
| `uc1` | Initial Setup | Basic welcome and input handling |
| `uc2` | Simple Comparison | Loop-based string reversal check |
| `uc3` | Enhanced Logic | Case sensitivity & special character handling |
| `uc4` | Strategy Pattern | Interface-based dynamic checking |
| `uc5` | Stack Implementation | Using `java.util.Stack` for reversal |
| `uc6` | Deque Implementation | Using `java.util.LinkedList` / `Deque` |
| `uc7` - `uc13` | Advanced Features | Recursion, Custom Exceptions, UI, etc. |
